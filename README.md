# つりリズム — ストーリー・有名曲アレンジ版

Godot向けの釣り音ゲープロジェクトです。

## ダウンロード

[改修済みプロジェクトZIP（約32MB）](https://github.com/bayyam1028-oss/Music/raw/refs/heads/main/fishing_rhythm_famous_music.zip)

ZIPを解凍し、`fishing_game/project.godot` をGodot 4.6以降で開いてF5で実行してください。

- 全10章のストーリー、10エリア・30釣り座
- MAPからエリアとキャストする釣り座を選択
- 場所ごとに異なる魚の抽選、進行状況の保存
- オリジナル曲と、クラシック・民謡・童謡・伝承曲の9主題による計165アレンジ
- 全曲／有名曲アレンジ／オリジナル曲の選曲切り替え

曲の出典と利用条件、操作方法、検証スクリプトはZIP内に同梱しています。
