# つりリズム：ストーリーモード試作

Godot 4.3以降で project.godot を開き、F6ではなくF5でプロジェクトを実行してください。
動作確認環境は Godot 4.6.3 です。

## 遊び方

1. タイトルの「ストーリーモード」を選択。
2. ワールドMAP右上の「冒険手帳」で依頼の場所・釣り座・対象魚を確認。
3. 金色の地点からエリアへ移動。最初は波止場のみ解放されています。
4. エリア内MAPの番号をタップし、釣れる魚を確認して「ここで釣りを始める」。
5. 長押しして離すとキャスト。既存の釣り音ゲーが始まります。
6. 指定の釣り座で対象魚を2匹釣ると次章・次エリアが解放されます。
7. 釣り画面右上の「MAPへ」で釣り座を変更できます。Escでも戻れます。

各章の会話と依頼は冒険手帳で読めます。全10章を達成すると全エリアで自由に釣れます。
依頼対象の魚は、その章が始まってから指定の釣り座で釣った分だけ数えます。
失敗やMAPへの帰還で依頼の匹数はリセットされません。
図鑑・ベスト記録・章・依頼の途中経過・場所別釣果は user://save.json に自動保存します。
既存セーブも読み込めます。既存の図鑑登録は保持し、ストーリーは第1章から始まります。

## 今回の実装範囲

10エリア、各3釣り座（計30か所）、10章の短い会話と釣り依頼、順次解放、エンディング文。
MAPは図形で描く概略図です。キャラクターを歩かせるフィールドや会話イベント演出は未実装です。
釣り座選択はマウス／タッチ操作。釣り音ゲーは従来のマウス／タッチ／Space操作に対応。

## 調整する場所

- scripts/journey_data.gd：エリア別の釣り座名、章ごとのセリフ。
- scripts/main.gd の _spot_indices()：釣り座ごとの魚の組み合わせ。
  現在はエリア内魚リストの0・1番が岸辺、1・2番が中間、2番以降が深場。
  場所内の出現率には既存のエリア別 weights と連続釣り補正を使用します。
- data/areas/*.tres：エリア全体の魚・出現率・背景・音ゲー難度。
- data/fish/*.tres：魚の売値やファイトの強さ。

## 検証

Godotのヘッドレステスト：

```
godot --headless --path . --script res://tests/journey_test.gd
```

テストは専用のユーザーデータ環境で実行してください。テスト自身がセーブを書き込みます。
30釣り座で計9000回の抽選、未解放エリアの制限、誤った釣り座で依頼が進まないこと、
10章の達成、セーブ復元、キャストから音ゲーへの遷移、MAP帰還を検証します。
ヘッドレス実行の終了時にGodotのリソース解放警告が出ます。
